⚠️ Syarat & Tata Cara (FFmpeg):
  1. Instalasi Termux (Sekali saja): pkg update && pkg install ffmpeg -y
  2. Buka video di Galeri → Klik / ketuk ikon titik tiga (...) → Pilih Rincian → Screenshot layarnya.
  3. Upload screenshot rincian itu ke kotak hijau di bawah (AI akan mendeteksi folder & nama file otomatis).
  4. Klik GENERATE & COPY, lalu Paste kodenya di Termux dan tekan Enter.
